  1. 1

    Frontier LLMs like Claude don’t come with uncertainty estimates, and their verbalized confidence is bad. We trained Pinocchio, a lightweight model that assigns confidence to outputs of popular API models, making it fast and easy to get well-calibrated uncertainty estimates. 📄🧵

    279/280
  2. 2

    First, a little background. Uncertainty estimation for LLMs is hard because (1) a model can phrase the same response many ways, and estimating the sum of their probabilities is expensive; (2) many API models don't expose features or logprobs, and we can't finetune them.

    270/280
  3. 3

    In a previous paper, we saw that a model (or probe) can be finetuned to output uncertainty estimates for its own responses. That strategy works, but it does not apply to API models, which are what everyone uses…
    Old paper: arxiv.org/abs/2406.08391

    247/280
  4. 4

    Pinocchio is trained to predict whether an LLM’s answer is correct from the prompt, LLM outputs, and target LLM ID. We need training data with examples of correct and incorrect responses so Pinocchio can learn the kinds of prompts and responses where LLMs perform well or poorly.

    279/280
  5. 5

    But datasets where frontier models struggle are scarce, so we aggregate a diverse collection of hard datasets to train on, importantly adding vision-language tasks where models are weaker. Pinocchio therefore handles vision problems at inference.

    246/280
  6. 6

    After training for correctness prediction, we can further calibrate Pinocchio post-hoc. What we get is a black-box uncertainty estimator that runs in a single forward pass and gets better with more training data. Pinocchio strongly outperforms baselines like verbal elicitation.

    278/280
  7. 7

    New post

    We also tested TypeSafe Jev, a commercial API built to return calibrated probabilities for decisions. It lands among the baselines at 0.67 AUROC, while Pinocchio reaches 0.86. (Jev was scored on the text-only subset, since it doesn’t take images.)

    247/280
  8. 8

    Pinocchio is also painless to incorporate in your codebase. It works across many API models and even transfers to target LLMs that it wasn’t trained on.

    152/280

    Disclaimer: Pinocchio can be miscalibrated for data distributions far away from our training mix. So we show how to finetune or re-calibrate Pinocchio to adapt it to new data distributions.
